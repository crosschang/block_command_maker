# TP 80-minute class plan

## Period 1 — 40 minutes

| Time | Stage | Goal |
|---|---|---|
| 0–3 | Opening | Confirm TP block and chat-command workflow |
| 3–11 | Basic 1 | Absolute coordinates |
| 11–19 | Basic 2 | Relative coordinates |
| 19–28 | Learning 1 | Registry search + selector type |
| 28–37 | Learning 2 | Teleport to another target |
| 37–40 | Review | Explain `@s`, absolute vs relative |

## Period 2 — 40 minutes

| Time | Stage | Goal |
|---|---|---|
| 0–3 | Review | Recall period 1 |
| 3–11 | Learning 3 | Rotation / facing |
| 11–20 | Advanced 1 | Local coordinates |
| 20–29 | Advanced 2 | Complex marker selector |
| 29–37 | Advanced 3 | `checkForBlocks` safe teleport |
| 37–40 | Challenge | Combine one or more concepts |

### Teacher preparation

- Prepare a safe practice area.
- If using Advanced 2, place an armor stand named `TP_MARK` before class.
- Keep the V2 smoke test URL available as a fallback.
- If Registry localization is not refreshed due to cache, open the new release in an incognito window.
